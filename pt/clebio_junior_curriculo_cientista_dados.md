## Projetos Selecionados

- **Detecção de Fraude em Transações** — Modelo de classificação para identificação de transações fraudulentas em dados altamente desbalanceados, com feature engineering, seleção de variáveis com Boruta e ajuste de hiperparâmetros. O modelo final em XGBoost alcançou 91,5% de acurácia balanceada e 94,4% de precisão em dados não vistos. Projeto com mais de 220 estrelas no GitHub. (github.com/juniorcl/transaction-fraud-detection)
- **Previsão de Prazo de Entrega em E-commerce (Olist)** — Modelo de regressão com LightGBM para prever o tempo de entrega de pedidos, com dados consumidos via SQL de banco containerizado em Docker, seleção de variáveis com mRMR, otimização com Optuna e interpretabilidade com SHAP. Redução de 66% no MAE frente à regra de negócio vigente, com deploy em API Flask. (github.com/juniorcl/olist-delivery-forecast)
- **DSToolkit — Biblioteca Python de Ciência de Dados** — Biblioteca modular com API inspirada no scikit-learn, reunindo pipelines de AutoML para classificação, regressão e clustering, métricas de avaliação (ROC, PR, KS, curvas de calibração, métricas de lift), diagnósticos de resíduos e utilitários de feature engineering. (github.com/juniorcl/data-science-toolkit)
- **Previsão de Vendas Rossmann** — Modelo de regressão para previsão de vendas diárias de lojas com até seis semanas de antecedência, incluindo análise exploratória, formulação e validação de hipóteses de negócio.
- **Health Insurance Cross-Sell** — Modelo de ranqueamento de clientes para aumentar a eficiência de campanhas de venda cruzada de seguros, avaliado com curvas de ganho acumulado e lift.
